# Configuration and commands

## `~/.config/phone-dash/config.toml`

Created by `phonedash` on first run. It is re-read on every service tick (30 s); commands and
the DMS plugin rewrite it and push it to the phone immediately. When the plugin saves it, the file
is regenerated with the standard comments (custom comments are lost).

```toml
phone = "galaxy-a53-5g"    # Tailscale (MagicDNS) name or IP address of the phone
port = 8765
language = "it"            # dashboard UI: "it" or "en"

[brightness]               # brightness % per time slot; each value holds until the next one
"07:00" = 15
"08:30" = 45
"19:30" = 20
"23:00" = 1

[screen]
night = ["23:00-07:00"]    # dimmed clock only
off = []                   # black screen (tap = on for 30 s), e.g. ["01:00-06:30"]
pc_offline_after = 90      # seconds without heartbeat => PC considered off => photo frame
on_lock = "frame"          # PC locked: "frame", "off" (black screen) or "none"
light_sensor = true        # scale the scheduled brightness with the phone's light sensor

[slideshow]
folders = ["~/Pictures/my_wallpapers"]   # scanned recursively (jpg, jpeg, png, webp)
seconds = 20               # time per photo
max_size = 2400            # long side (px) of the photos sent to the phone

[billable]                 # Billable Hours: Google Sheets backup web app of the watchapp
url = ""
token = ""

[player]
animation = "30s"          # wave and cover: "off", "30s" (after track change/touch), "always"
lyrics = true              # synced lyrics (LRCLIB) in the photo frame

[notes]
items = []                 # post-its (max 6, 200 chars each)

[layout]
tabs = ["notifications", "agenda", "home", "photos", "weather", "pc"]   # order; remove to hide
show_billable = true
show_notes = true
```

Ranges (`"HH:MM-HH:MM"`) may wrap past midnight. The light sensor multiplies the scheduled value
by 0.35 (dark room) … 1.4 (direct light).

## `phonedash`

| Command | What it does |
|---|---|
| `phonedash run` | service loop (used by `phonedash.service`) |
| `phonedash pair` | read the phone's token over USB (adb) into `~/.config/phone-dash/token` |
| `phonedash status` | phone status as JSON |
| `phonedash brightness 30\|auto` | brightness override until the next slot |
| `phonedash screen on\|off\|auto` | screen override until the next schedule change |
| `phonedash sync-photos` | sync the slideshow folders now, with progress |
| `phonedash schedule` / `set-schedule JSON` | read/write `[brightness]` + `night`/`off` |
| `phonedash notes` / `set-notes JSON` | read/write post-its (`["text", …]`) |
| `phonedash layout` / `set-layout JSON` | `{"tabs": […], "show_billable": bool, "show_notes": bool}` |
| `phonedash animation [off\|30s\|always]` | player animation |
| `phonedash option NAME [VALUE]` | `lyrics on\|off`, `light on\|off`, `on_lock frame\|off\|none`, `slideshow SECONDS`, `language it\|en` |
| `phonedash options` | all options as JSON |
| `phonedash google-token TOKEN` | link Google Home with an `oauth_token` from a browser |

## Settings stored on the phone

Set from the dashboard itself (long press → drawer), kept in the app's private preferences:

* weather city (blank = phone location);
* hidden calendars, hidden apps, hidden Google Home devices;
* Google Home sign-in (master token).

## Files

| Path | Content |
|---|---|
| `~/.config/phone-dash/config.toml` | the configuration above (0600) |
| `~/.config/phone-dash/token` | phone API token (0600) |
| `~/.config/systemd/user/phonedash.service` | generated by `pc/install.sh` |
| `~/.config/dms/plugins/phoneDash` | symlink to `dms-plugin/phoneDash` |
